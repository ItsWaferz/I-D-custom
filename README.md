# I&D Custom - Premium Auto Customization

Un website modern și interactiv pentru **I&D Custom**, specializat în servicii premium de customizare auto: retapițare plafoane, vopsire elemente plastic și sisteme de lumini ambientale.

## 🚀 Tehnologii Folosite

Acest proiect a fost dezvoltat folosind tehnologii moderne pentru o performanță optimă și animații fluide:

- **[React](https://reactjs.org/)** (cu **[Vite](https://vitejs.dev/)**) - Pentru o dezvoltare rapidă și o experiență de utilizator excelentă (SPA).
- **[Tailwind CSS](https://tailwindcss.com/)** - Pentru un design responsive, modern și personalizat.
- **[Framer Motion](https://www.framer.com/motion/)** - Pentru tranziții și animații fine ale elementelor UI.
- **[React Router](https://reactrouter.com/)** - Pentru navigarea între pagini fără reîncărcare.
- **[EmailJS](https://www.emailjs.com/)** - Pentru trimiterea automată a formularelor de contact și a cererilor de ofertă direct pe email.

## 💡 Funcționalități Principale

- **Calculator Prețuri Inteligent:** Utilizatorii pot selecta opțiunile dorite (materiale plafon, tip caroserie, zone lumini ambientale) și obțin instant o estimare de preț.
- **Formular de Contact Sincronizat:** Opțiunile alese în calculator sunt transmise automat către formularul de contact.
- **Design Responsive:** Optimizat pentru a arăta perfect pe orice dispozitiv (desktop, tabletă, telefon).
- **Dark Theme Elegant:** O tematică vizuală premium, cu nuanțe de negru profund și accente aurii (gold gradients).

## 🛠 Instalare și Rulare Locală

Dacă dorești să rulezi proiectul local:

1. Clonează repository-ul:
   ```bash
   git clone https://github.com/ItsWaferz/I-D-custom.git
   ```
2. Instalează dependențele:
   ```bash
   npm install
   ```
3. Pornește serverul de dezvoltare:
   ```bash
   npm run dev
   ```

## 🌐 Deploy pe Vercel

Acest proiect este optimizat pentru a fi urcat direct pe **Vercel**.
La importarea repository-ului în Vercel:
- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
